# 正式实验：单人、三张地图、三个条件

当前设计标识为 `single_driver_3maps_v1`，只安排当前驾驶者 `P001`。三张地图各进行一次 Hold、TiRex、manual_tirex，共 **9 组**。此文件替代旧部署文档中的多人、长路线正式采集安排。每一组都由驾驶者手动启动，结束后检查结果再继续；程序不会接着启动下一组。

## 条件

| 命令条件 | 转向输入 | 自动横向控制 | 纵向控制 |
|---|---|---|---|
| `hold` | 固定延迟 300 ms 后，保持最新收到值 | MPC + PPO 共享控制 | PID，目标 30 km/h |
| `tirex` | 相同延迟历史，由当前 TiRex 预测 | MPC + PPO 共享控制 | 同上 |
| `manual_tirex` | 与 `tirex` 相同的延迟、当前 TiRex 和回退机制 | 真人独立转向，自动侧权重恒为 0，不加载 MPC/PPO | 同上 |

`manual_tirex` 对应本次要求的“纯手动驾驶”：驾驶员独立控制转向，程序控制油门和制动。TiRex 继续保留；预测无效或无覆盖时使用已收到的 Hold，绝不旁路读取未延迟输入。它不表示车辆自行驾驶。各条件采用相同的方向盘尺度和输出限幅，当前不发送力反馈。

## 地图和任务

| 地图参数 | 实际地图 | 参考路线长度 | 障碍与绕行 |
|---|---|---|---|
| `town03` | Town03_Opt | 约 291 m | 弯道，两处固定停放车辆，需要向左借道绕行后回归 |
| `town04` | Town04 | 约 313 m | 弯曲公路，两处固定停放车辆，左右交替绕行 |
| `town05` | Town05 | 约 306 m | 城市路段，两处固定停放车辆，左右交替绕行 |

Town03 使用同一道路几何的分层地图 `Town03_Opt`，避开本机完整版 Town03 的 Vulkan 渲染崩溃。三个场景的坐标、参考路线和障碍位置已固定在 `configs/scenarios/*.json`。同一地图的三个条件使用相同场景、晴天、车辆和速度目标。当前障碍物为静态车辆，没有随机交通或行人。

沿画面中的绿色参考线通过障碍并到达终点；右上角概览显示路线、障碍和自身位置。参考线已包含绕障路径，横向 RMSE 与偏离判断也使用这条路径，不会把按要求绕障本身算作偏离原车道中心。

计分行驶目标为 **30–45 秒**，不包含服务器切图、模型加载、预热及停车积累历史的时间。每趟先停车积累至少约 7 秒历史，预测条件还需等待首条可用预测。达到终点、碰撞、偏离参考路线超过 5 m、计分达到 90 秒，或手动退出时结束。未完成、失败和中断的数据都保留。

## 九条启动指令

在 Ubuntu 桌面终端执行：

```bash
cd /home/patton/cooperative_driving
```

**每次只运行下面一行。** 命令会启动或准备对应的 CARLA 地图，然后只运行这一组。新地图首次启动可能需要一些时间；模型预热不计入驾驶时间。方向盘继续保持 PC 模式、360° 设置。

| 组 | 地图 | 条件 | 启动指令 |
|---|---|---|---|
| 1 | Town03 | 共享 Hold | `bash scripts/run_formal.sh --map town03 --condition hold` |
| 2 | Town03 | 共享 TiRex | `bash scripts/run_formal.sh --map town03 --condition tirex` |
| 3 | Town03 | 真人独立转向 + TiRex | `bash scripts/run_formal.sh --map town03 --condition manual_tirex` |
| 4 | Town04 | 共享 TiRex | `bash scripts/run_formal.sh --map town04 --condition tirex` |
| 5 | Town04 | 真人独立转向 + TiRex | `bash scripts/run_formal.sh --map town04 --condition manual_tirex` |
| 6 | Town04 | 共享 Hold | `bash scripts/run_formal.sh --map town04 --condition hold` |
| 7 | Town05 | 真人独立转向 + TiRex | `bash scripts/run_formal.sh --map town05 --condition manual_tirex` |
| 8 | Town05 | 共享 Hold | `bash scripts/run_formal.sh --map town05 --condition hold` |
| 9 | Town05 | 共享 TiRex | `bash scripts/run_formal.sh --map town05 --condition tirex` |

按 Esc、关闭窗口或在启动终端按 Ctrl+C 可结束当前趟。退出会停车、销毁本趟车辆和传感器并恢复异步设置。每次运行都创建新的带时间戳目录，不覆盖旧结果。一次只允许一个试验进程。

## 数据与指标

每次终端打印 `Run output: ...`，记录该目录以便检查。

| 文件 | 内容 |
|---|---|
| `config.json`、`scenario.json`、`scene.json` | 条件、参与者、参数、版本、固定参考路线，以及实际生成的障碍物位置和包围盒 |
| `trajectory.csv` | 每个已观测物理 tick 的坐标、朝向、速度、加速度、CARLA frame、仿真与墙钟时间、路线进度和上一拍施加的控制，含准备和终止帧 |
| `scoring_reference.csv` | 评分使用的固定参考路线，世界坐标以米为单位 |
| `reference_route.csv` | 规划器样条参考路线及朝向、曲率 |
| `ticks.csv` | 原始转向、已收到转向、实际选中估计、融合权重、自动/混合/施加转向、延迟及控制时序 |
| `bridge-*.jsonl` | 原始输入、接收事件、预测发布和推理记录 |
| `summary.json`、`metrics.json` | 完成、碰撞、结束原因、横向 RMSE、转向估计 MAE/RMSE、实测输入年龄、推理耗时及回退比例 |

**正式运行逐帧只保存数值数据，不保存视频、图片序列或自动导出的图片。** 相机仅用于实时驾驶显示。`yaw_rad` 为弧度，位置为 CARLA 世界坐标；车辆速度分量使用车体坐标。完整绘图所需的路线和障碍几何随每趟保存。

完成后可重新分析指定目录；需要画图时再显式加 `--plot`，每趟输出一张 PNG 和一份 SVG：

```bash
source scripts/env.sh
"$HOCD_PYTHON" -B scripts/analyze_run.py runs/实际目录名
"$HOCD_PYTHON" -B scripts/analyze_run.py --plot runs/实际目录名
"$HOCD_PYTHON" -B scripts/summarize_formal.py
```

九组汇总仅接受当前设计、`formal:true`、`diagnostic_input:false` 的记录。保留同组的全部尝试和未完成记录，不自动挑选最好结果。旧路线记录和准备阶段程序输入记录不进入这九组。
